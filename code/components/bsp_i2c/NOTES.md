## EEPROM（AT24C02，第二十章）

### 硬件
- AT24C02，容量 256 字节，7 位地址 `0x50`（8 位写地址 `0xA0`）。

### 原理要点
- **EEPROM**：掉电不丢失的存储器，通过 I2C 读写。
- **写时序**：START → 器件地址(W) → 存储地址 → 数据 → STOP；写完后需延时等待内部写入周期（约 5~10ms）。
- **读时序**：START → 器件地址(W) → 存储地址 → 重复 START → 器件地址(R) → 读数据 → STOP。
- AT24C02 页大小 8 字节，跨页写需分段；更大容量（AT24C04+）地址位会并入器件地址。

### 宏设计
- `BSP_EEPROM_ADDR` / `BSP_EEPROM_SIZE`。

### 验证结果

- ✅ 编译通过，烧录成功
- ✅ 写入 `ESP32S3` → 读回一致，`EEPROM read/write OK`
- ✅ 3 秒后再次读回，数据保持（掉电不丢失）
