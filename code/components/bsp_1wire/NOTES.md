# 单总线（DS18B20）学习笔记

## 硬件
- DS18B20 数字温度传感器，单总线 DQ=IO0（需跳线帽连接 WIRE_DQ ↔ IO0）。
- 数据线开漏 + 上拉，DQ 既可输出也可输入。

## 原理要点
- 单总线只有一根数据线，主机通过精确时序读写位。
- 复位：主机拉低 480us 释放，DS18B20 拉低 60~240us 作存在脉冲。
- 写 0：拉低 60us；写 1：拉低 2us 后释放。
- 读位：拉低 2us 释放，~15us 时采样。
- 读温度流程：复位 → SkipROM(0xCC) → Convert(0x44) → 等 750ms → 复位 → SkipROM → ReadScratchpad(0xBE) → 读 2 字节。
- 12 位分辨率，0.0625°C/LSB，温度 = 原始值 / 16。

## 宏设计
- `BSP_1WIRE_GPIO`。

## 验证结果

- ✅ `DS18B20 init OK (DQ=GPIO0)`，1-wire 复位/读写时序正常（能正确判断「无器件」）
- ⏳ 待插跳线帽（WIRE_DQ ↔ IO0）+ 接 DS18B20 模块后，读取实际温度
